# Build Commands
- `hugo server` - Start development server 
- `hugo` - Build static site
- `hugo new content/posts/my-post.md` - Create new post

# Code Style
- Content files use markdown (.md) in content/ directory
- Post front matter must include title, date, and draft status
- Content follows standard markdown conventions
- Images go in static/ directory
- Custom layouts go in layouts/ directory
- CSS/JS assets go in assets/ directory
- Site config in hugo.toml
- Use categories and tags in post front matter for organization

# Conventions
- Keep content focused and minimal
- Use semantic HTML in layouts
- Follow Hugo best practices for templates
- Organize content logically in subdirectories
